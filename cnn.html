Convolutional Neural Network (CNN)

A convolution slides a small learned kernel across the image, and at every position computes one number: the sum of the kernel's weights multiplied element-wise with the pixels underneath it. That single scalar becomes one pixel of the output feature map — repeating this everywhere turns a full image into a map of "how strongly does this pattern appear here."

Bright output cells mark where the kernel's pattern (a vertical brightness change) lines up with the image. In a real CNN dozens of kernels run in parallel, and their weights are learned by backpropagation rather than hand-set.
