MLP — Multilayer Perceptron

Every connection carries a learned weight; every node sums its weighted inputs, adds a bias, and passes the result through a nonlinear activation function. Stacking these layers lets the network build increasingly abstract combinations of the raw input features.

Reading the diagram

Input nodes (left) hold raw feature values. Each hidden node computes ReLU(Σ wᵢxᵢ + b) — negative sums get clipped to zero, which is why some hidden nodes stay dark even with a fully-connected layer before them. The output layer uses a sigmoid so its two nodes read as class probabilities.
