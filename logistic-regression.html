Logistic Regression

Logistic regression scores each point with a linear function z = wx + b, then squashes that score into a 0–1 probability with the sigmoid function σ(z) = 1 / (1 + e⁻ᶻ). A point is classified positive when its predicted probability crosses a decision threshold — usually 0.5.

Why sigmoid, not a straight line

A plain linear model can predict values below 0 or above 1, which makes no sense as a probability. The sigmoid curve is monotonic and bounded in (0, 1), so its output can always be read as "probability of the positive class." The weights are fit by gradient descent to maximize the likelihood of the observed labels.

Regularization (λ)

Raising λ adds a penalty λw² to the loss, pulling the weight toward zero each step. A small λ barely changes the fit; a large one flattens the sigmoid into a near-horizontal curve, since the model would rather predict a cautious probability near 0.5 everywhere than commit to a steep, confident boundary.
