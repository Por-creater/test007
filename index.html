Machine Learning Algorithms, Visualized

Each algorithm gets its own page with a short explanation and a live, interactive diagram — drag points, step through iterations, and watch the algorithm work. Built with plain HTML, CSS and SVG/Canvas — no frameworks, no build step, deployed straight from this repo with GitHub Pages.

Supervised Learning
01 Linear Regression Fit a line through points by minimizing squared error. Drag points, watch the fit and residuals update. 02 Logistic Regression Squash a linear score through a sigmoid to output class probability. Move the decision threshold. 03 k-Nearest Neighbors Classify a new point by majority vote among its k closest labeled neighbors. 04 Decision Tree Recursively split the feature space on the axis and threshold that separates classes best. 05 Random Forest An ensemble of trees, each trained on a bootstrap sample, voting together on the final label. 06 Support Vector Machine Find the hyperplane with the widest margin between classes, anchored on the support vectors. 07 K-Means Alternate between assigning points to the nearest centroid and moving centroids to the mean. 08 MLP (Neural Network) Layers of weighted connections and nonlinear activations passing a signal forward. 13 XGBoost Gradient boosting: each new shallow tree is fit to correct the residual errors of the ones before it. 14 Stacking Several base models' predictions become input features for a meta-model that blends them.
Unsupervised Learning / Deep Learning
09 CNN A small kernel slides across the image, computing a weighted sum at every position to build a feature map. 10 LSTM Gated memory cell that learns what to forget, what to write, and what to output at each time step. 11 Transformer Self-attention lets every token weigh every other token when building its representation.
Reinforcement Learning
12 Reinforcement Learning An agent explores a grid world, updating a Q-table from rewards until a policy emerges.
