Support Vector Machine (SVM)

A linear SVM looks for the hyperplane that separates two classes with the widest possible margin. Only the points closest to the boundary — the support vectors — determine where it sits; every other point could move and the boundary wouldn't change.

Lower C allows more margin violations (a softer, wider margin that tolerates overlap); higher C pushes the boundary to classify every point correctly, even if the margin narrows and more points become support vectors.

Trained with subgradient descent

This page fits a soft-margin linear SVM by minimizing the hinge loss max(0, 1 − yᵢ(w·xᵢ+b)) plus an L2 penalty ‖w‖²/(2C) via gradient descent — the same objective a QP solver would reach exactly, just approximated iteratively so it can retrain instantly in the browser.

Class weight

Real datasets are often imbalanced, and sklearn's class_weight parameter lets you tell the SVM to care more about mistakes on one class than the other. Sliding toward "favor +1" scales up the penalty for misclassifying blue points, so the boundary shifts away from blue to protect it — even though nothing about the data itself changed.
