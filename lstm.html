LSTM — Long Short-Term Memory

At every time step an LSTM cell decides three things with learned gates: how much of the old memory to forget, how much of the new candidate value to write in, and how much of the memory to output as the hidden state. That gating is what lets it carry information across many steps without it decaying or exploding.

Gate values sit in (0, 1) — near 0 means "block," near 1 means "pass through." Watch the forget gate: when it's low, the cell state resets toward the new candidate value instead of carrying the past forward.
