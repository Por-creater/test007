Linear Regression

Linear regression fits a straight line y = wx + b through a set of points by choosing w and b to minimize the sum of squared vertical distances (residuals) between the line and every point — the "least squares" fit.

How the fit is computed

With n points, the closed-form least-squares solution is w = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)² and b = ȳ − w·x̄. This is the same line that a single step of gradient descent converges to when trained on squared error — regression has an exact algebraic solution, no iteration required.
